# SecuArt — UI/UX Design Project

**Semester project for the “Interaction Design” course**  
University of Applied Science RheinMain | Summer Semester 2025

---

## 📌 About the Project

As part of the “Interaction Design” course, our team worked through the complete UI/UX design process, from the initial concept to clickable prototypes. The goal was to apply user-centered design methods to create a coherent and accessible experience for a museum security platform.

---

## 🎯 What We Created

- **Low- and high-fidelity wireframes**
- A **visual identity** with colors, typography, and a style board
- **Desktop and mobile screen designs** using 12-column and 4-column grids
- Reusable **UI components** in Figma
- Clickable **prototypes** with interactive navigation, hover states, and FAQ elements
